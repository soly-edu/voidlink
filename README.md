# 虚连之路

奇幻玄幻小说 · 多智能体协同创作引擎

## 项目概述

讲述一名男子在醉酒后意外开启灵魂与肉体的"虚连接"，从此能够触碰灵体。随着虚连接逐渐加深，他将获得强大的力量，并最终在神秘女子的帮助下完成真正的虚连接——肉体与灵魂同时强化，成为神灵。

## 世界观设定

- **虚连接**：灵魂与肉体之间的特殊连接状态，开启后可触碰/看到灵体
- **灵原石**：神秘女子给予的机缘之物，是完成真正虚连接的关键
- **冥界**：与人界处于同空间但不同次元，人类死后的灵魂可被传输至此
- **坐化**：简化版的虚连接，肉体和灵魂强度有限
