## 模块1: 本章创作目标

### 宏观目标
- **本章核心任务**: 肖德胜接管局面，林韵初步感知自身异常，干尸事件的调查启动，揭示更多超自然线索
- **叙事阶段**: 上升（从危机爆发进入应对与探索）
- **与前章的衔接**: 第2章结尾肖爸抵达 → 第3章开头肖爸率众进入别墅查看现场，无缝衔接

### 微观目标
1. 展现肖德胜的专业应对能力，暗示他对超自然事件有经验/准备
2. 林韵的身体异常（左腿痊愈）被更多人注意到，引发初步质疑与自我怀疑
3. 发现更多干尸线索（12个死者死法是否一模一样？房间符箓的意义？），推进FP003和FP004
4. 林韵内心从"震惊"过渡到"困惑+不安"，为后续探索埋下情感基础
5. 周叔（明面：武力冲突/警察/军人处理）和高大男子（暗面：清理尸体/情报收集）的职能初步展现

### 必须覆盖的伏笔
- FP002: 十二面体入神庭穴 → 本章推进：林韵开始感知身体的微妙变化（无意识的感知，尚未明确认知）
- FP003: "献十二活灵，祭太阴" → 本章推进：肖爸或周叔发现12个死者死法一模一样
- FP004: 符箓封条房间 → 本章推进：肖爸注意到该房间，暗示他知道这个房间的存在
- FP005: 肖德胜携手下赶来 → 本章回收：展现周叔和高大男子的专业行为，验证"有备而来"
- FP006: 林韵感觉别墅有东西 → 本章推进：林韵再次感受到微弱的灵异感知

## 模块6: 质量红线

### OOC禁区
- **林韵**: 绝对不能突然变成热血英雄/冲动行动者——他是咸鱼心态的普通人，面对超自然事件应保持"理性压抑"但内心不安
- **肖能**: 不能突然变得成熟冷静——他刚经历崩溃，本章应是麻木而非恢复
- **肖德胜**: 不能对林韵的异常直接摊牌——他的反应应该是"注意到→沉默→暗中关注"，不能明说
- **周叔**: 不能主动向林韵解释超自然现象——他的定位是低调执行者

### 机制禁区
- #机制:虚连接体系: 本章不能让林韵明确认知自己已虚连接——他只能有"微妙感知"，不能"顿悟"
- #物品:灵原石: 不能在本章直接出场或被林韵发现——十二面体仍是隐藏状态

### 叙事禁区
- 不能提前揭示琉璃与干尸事件的直接因果关系（FP003只推进死法一致的发现，不揭示仪式关联）
- 不能让肖德胜对符箓封条房间做完整解释——只能暗示他知道
- 不能在本章解决任何核心悬念——本章是"调查启动"而非"真相揭露"

### 伏笔回收指令
- **FP005（肖德胜携手下）**: 本章回收——周叔和高大男子的行为验证"有备而来"
- **FP003（仪式与干尸）**: 本章推进——发现12个死者死法一模一样
- **FP004（符箓封条房间）**: 本章推进——肖爸注意到该房间，反应异常
- **FP002（十二面体入神庭穴）**: 本章推进——林韵路过触发点时身体微弱反应
- **FP006（林韵灵异感知）**: 本章推进——再次感受到微弱灵异气场


### 群像线补强建议（来自Ag3-NWB质控）
- 在调查过程中，通过肖能的反应、遗留物（手机、衣物、半杯酒）等方式为已故友人建立片段印象，避免读者对十二人的死亡无感
- 可通过管家/保洁的视角补充一两个友人的生前片段
